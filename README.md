## Interactive Task Management Page 

### Author
Oze Osakue

### The Desciption

The Interactive Task Management Page is a type of web application
that enables users to create and manage tasks. Users can enter a 
task, select a priority level, specfically, either Low, Medium, or High, add the task to the page, mark a task as done, and remove a task. This application was created using the following languages: HTML, CSS, and JavaScript. 

### How to Run the Program

1. Either clone or download the GitHub repository.
2. Open the project folder in Visual Studio Code (VSC).
3. Open 'index.html' using either Live Server or open the file directly in a web browser.
4. Enter a task in the task input box.
5. Select a specific priority level.
6. Click **Add Task** to add that task.
7. Click **Complete** to mark that task as completed.
8. Click **Delete** to remove that task.

### Known Problems or Incomplete Features
The tasks aren't saved after the webpage is refreshed. There 
are currently no other known problems.
